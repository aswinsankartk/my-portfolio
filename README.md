# My Portfolio

This is my personal portfolio site — where I put up the projects I've actually built and shipped, instead of just listing them on a resume.

It's a single-page site with server-rendered sections, built with the App Router so it stays fast and SEO-friendly without needing separate pages for everything.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Projects featured

**BingeStudy** — a collaborative study platform, built with Next.js 14, Tailwind, shadcn/ui, and Supabase (Postgres, Auth, Storage, Realtime), with Google Gemini 2.5 Flash wired in for AI features. This was my BCA final year project. [Live](https://bingestudy.vercel.app)

**Saldo** — a personal finance app for tracking expenses and splitting them with friends. Built on the MERN stack (Express/MongoDB backend so far), with JWT auth and bcrypt-hashed passwords. Still a work in progress — backend-first, frontend coming later.

## Running it locally

```bash
git clone https://github.com/aswinsankartk/my-portfolio.git
cd my-portfolio
npm install
npm run dev
```

Actively being built out — this is a rewrite of an earlier version, moving from plain HTML/CSS/JS to Next.js for better performance and SEO.
